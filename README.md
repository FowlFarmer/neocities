# neocities
Fowl Farmer's Neocities Website.


Neocities is a modern revival of the old-school web—a place where you can build your own site from scratch, free from algorithms and corporate control. It’s about creativity, self-expression, and the joy of making something truly yours. In a world of templated react personal websites, Neocities feels like a true digital home you shape with your own hands.

(Plus I am not a web dev nerd so I don't mind if it is not react/flutter)

This is my Neocities website which is updated when I feel like it through the Neocities CLI tool using Ruby. You can check out neocities (and create your own website) here: https://neocities.org/
